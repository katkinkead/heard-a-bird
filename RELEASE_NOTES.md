# Songsketch 0.1.2 — Sir Gold Finchley takes the chair

The guide now introduces Sir Gold Finchley the Sixth, uses the requested vocalist caption, and opens its inventory as **Your Fieldguide of Parts**. A single **Next** action saves the step and advances; the separate completion checkbox is gone. Bird navigation browses without marking steps finished, and earlier eight-step progress migrates without marking the new BirdNET step complete.

There are now nine steps, including dedicated BirdNET readiness: microphone power and capture, location/time, bundled v2.4 model, Balanced 0.7 threshold, owl/night settings, persistent detection records, audio retention, API access and actual recognition checks. The Pi installer also checks arm64 userspace and a real ALSA capture device instead of accepting HDMI playback alone.

Private remote-viewing instructions explain how to watch away from home. Songsketch remains local-network-only until that optional connection is configured; no VPN, account or sharing permissions were installed or changed in this release.

**Verification:** guide navigation, saved progress, absence of the old checkbox, reset, desktop/mobile layout, JavaScript syntax, package preflight, shell syntax and all 11 Pi tests pass. The original application retains its 78-test Mac/Linux verification; actual Pi/audio, reboot and remote viewing checks still require the installer’s equipment. Exact microphone/interface compatibility must be confirmed. Existing authenticated BirdNET installations need a separate durable access plan because this relay does not refresh expired BirdNET access tokens.

Extract the ZIP and open **Start Songsketch.command** on the Mac. The software, five approved paintings and field guide travel together. The repository and release are private.
