# Songsketch 0.3.0 — the little team, all together

The guide now starts with the MVP shopping list, then moves through Pi preparation, Pi details, connecting a local AI, and live installation checks. The assistant fetches this private GitHub repository and operates its existing setup tools. On first use, the guide downloads an executable-preserving ZIP launcher; subsequent connections open the installed assistant in Terminal. Normal sign-in, SSH identity checks and permissions remain in place.

- The Amazon list is Step 0. The Clippy microphone is linked separately; the two windshield options are alternatives.
- The portable art library includes 45 finished references with retained acceptance history, the latest fork style/animation guides, status graphics, and five completed 75-second animations. Unfinished animation work stays out of playback.
- Missing final artwork and missing animation are separate. Only genuinely missing artwork enters the email queue; known portraits awaiting animation appear in the dashboard. The recipient and SMTP details stay in private runtime configuration.
- The dashboard includes recording history, selected-period diversity counts/distribution and CSV export. Counts are qualifying detections, not individual birds.
- Setup health identifies the affected component, failed checkpoint and evidence. Pi power/temperature telemetry, persistent diagnostics and bounded recovery support the local assistant. Routine playback and recovery require no paid AI key.
- The production plan preserves the Canva architecture, names the proposed power components and includes a guarded Pi 5 USB-current helper. It never suppresses a genuine supply fault or applies production settings to the MVP automatically.

**Verification:** 195 automated application tests and eight animation-import tests pass locally. Package preflight verifies 45 references, five completed animations and 50 asset hashes. Generated launcher, JavaScript and shell checks pass. The guide's desktop journey, private-session opening, component status and reference gallery were checked in the running local application. The new narrow-screen check could not be confirmed because the preview retained its desktop viewport.

**Still to commission:** physical Pi/audio, real BirdNET recognition, power chain, reboot/network recovery, actual SMTP delivery and the eventual unattended host. No external email, real SSH installation or paid AI request was made during verification.

Open `guide/index.html` after extracting the complete release. Choose **Connect my AI & install** after preparing the Pi and adding its details. The GitHub route needs access to this private repository and a local Codex or Claude Code installation. If using a supplied offline copy, open that repository in a local assistant and have it follow `AGENTS.md` and `docs/ai-setup.md`. The browser alone cannot write an SD card or start local programs.
